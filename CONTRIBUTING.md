# Contributing to Hearth 🔥

Thank you — contributions are genuinely welcome. Hearth is a one-maintainer labor of
love, and help makes it better.

## The short version

- **Read every line, run it, learn from it, improve it.** That's the point of the source
  being public.
- **Contribute via fork + pull request.** Only the maintainer (Kevin Champlin) merges.
- **Don't fork it into your own competing product.** The license (FSL-1.1-MIT — see
  `LICENSE.md`) permits any use *except* competing use, and the Hearth name/branding are
  reserved (`TRADEMARK.md`). Each release automatically becomes plain MIT two years after
  it ships — protection now, fully open later.

## How to contribute

1. **Open an issue first** for anything bigger than a typo — let's agree on the shape
   before you spend an evening on it.
2. Fork → branch → make the change → pull request with a clear description of what and why.
3. Match the existing style: plain language in user-facing copy (a non-technical person
   should understand every word), warm visuals, no jargon, privacy first. Nothing that
   sends user data anywhere — ever. That rule has no exceptions.
4. The maintainer reviews everything personally. Small, focused PRs merge fastest.

## Contribution terms

By submitting a contribution (pull request, patch, or suggestion) you agree that:

- Your contribution is licensed to the project under the project's current license
  (FSL-1.1-MIT), and
- You grant Kevin Champlin a perpetual, worldwide, irrevocable license to use, modify,
  and **relicense** your contribution as part of Hearth.

This keeps the project's licensing future in one pair of hands instead of requiring
sign-off from every past contributor. It's the lightweight version of a CLA.

## Other ways to support

- ⭐ Star the repo — it genuinely helps people find Hearth.
- 🐛 Report bugs and rough edges (especially from non-technical friends and family!).
- 💬 Tell one person about it: "It's a free AI that runs on your own computer — it even
  works with the wifi off."
